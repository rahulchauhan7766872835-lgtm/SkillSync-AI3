
# 🚀 SkillSync AI — Student Skill & Project Team Matcher

SkillSync AI is an AI-powered platform that helps students find suitable teammates for college projects and hackathons based on their technical skills, interests, and project requirements. It uses **Gemma 4** to generate team recommendations and explain the matching results.

## 🎯 Problem Statement

Students often struggle to find teammates with complementary skills for projects and hackathons. SkillSync AI aims to simplify team formation by analyzing student profiles and project requirements.

## 💡 Solution

SkillSync AI analyzes available student profiles and project details to recommend a suitable team. It can help identify matching skills, shared interests, and potential skill gaps.

## ✨ Features

- 👨‍🎓 Student skill and interest profiles
- 📋 Project requirements and team-size information
- 🤖 AI-powered team recommendations using Gemma 4
- 📊 Rule-based student–project compatibility scoring
- 🧩 Support for identifying complementary skills and skill gaps
- 📝 AI-generated team recommendation reports

## 🛠️ Tech Stack

- Python
- Google Colab
- Gemma 4
- Hugging Face Transformers

## ⚙️ Getting Started

### Requirements

- A Google account
- Google Colab
- Hugging Face access to the Gemma model, if required
- Any required packages and runtime configured in the notebook

### Run the Project

1. Clone or download this repository.
2. Open `SkillSync_AI_Gemma4.ipynb` in Google Colab.
3. Configure the runtime and install the required dependencies.
4. Authenticate with Hugging Face if the model requires access.
5. Run the notebook cells in order.
6. Enter or select a project and review the generated recommendations.
